# Design

## Visual Direction

AfiaCare is a civic wellness product, closer to a public-health command workspace than a lifestyle app. It should feel precise, grounded, and quietly capable. The product should not lead with generated imagery, oversized hero treatments, or soft wellness-card repetition.

## Color

Use an off-white base, white content surfaces, navy blue for structure and primary action, baby blue for calm active states, soft yellow for civic emphasis, and beige for quiet dividers and secondary surfaces. Restrained red appears only for risk or safety cues. Avoid purple-blue AI gradients, saturated wellness greens, and decorative color overload.

## Typography

Use one system sans family for all UI. Keep headings fixed-size and readable, not fluid-display. Labels, buttons, and data should use the same vocabulary throughout.

## Layout

Use an app shell: persistent desktop sidebar, compact mobile top bar, and page content in a constrained work area. Prefer rows, queues, split panes, logs, and status bands over repeated identical card grids. Use cards only for distinct records or compact summaries.

## Components

Controls use 8px radius, 44px minimum touch targets, visible focus rings, consistent hover states, and clear disabled/loading states. Avoid border plus wide drop-shadow combinations.

## Motion

Motion is limited to short state feedback and hover transitions. Content must be visible by default and respect reduced motion.
